WebSerial is a remote terminal to log, monitor or debug your firmware over a wireless connection.  It lives in your embedded device and works in any modern web browser.

## Features

- 🔥 Quick Remote Debugging
- 💾 Data Monitoring & Recording
- ⚙️ Firmware Debugging
- 📝 Save Logs as `Text`/`CSV`/`JSON`

<br/>

<Callout emoji="🚀">
This documentation serves both WebSerial Lite & Pro. Therefore, if you notice **Pro** mentioned on any of the features in the documentation, it means that particular feature is only available in <a href="https://webserial.pro">WebSerial Pro</a>.
</Callout>
